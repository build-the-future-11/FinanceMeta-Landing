# FinanceMeta Reference Notes

References expand the interaction vocabulary. They do not define FinanceMeta's branding, copy, or page composition.

## Our World in Data Grapher

Source: https://ourworldindata.org/redesigning-our-interactive-data-visualizations

Useful properties:

- Data sources stay visibly attached to the thing they support.
- Contextual controls change with the current view.
- Rules, tables, charts, and annotations carry the identity without decorative chrome.
- Mobile and full-screen behavior are treated as primary states.

Transfer to FinanceMeta: show development status and evidence standards beside every program claim. Use lines, indices, and source-like annotations as the visual grammar.

## Godly finance collection

Source: https://godly.website/websites/finance

Useful properties:

- Financial sites can feel precise without imitating a bank dashboard.
- Large typography and animated systems work when supporting structure remains quiet.
- The strongest examples commit to one memorable visual behavior.

Transfer to FinanceMeta: one animated flow field carries the expressive load. The rest of the page stays typographic and disciplined.

## Stripe Apps reference

Source: https://godly.website/website/stripe-apps-772

Useful properties:

- Complex systems become understandable through directed paths and clearly bounded objects.
- Technical annotations can coexist with generous brand-scale type.

Transfer to FinanceMeta: use the learning-to-lead route as real information, not a decorative workflow diagram.

## Motion Primitives

Source: https://motion-primitives.com

Useful properties:

- Small motion primitives can be composed without importing a visual identity.
- Motion should respect reduced-motion preferences and retain a stable resting state.

Transfer to FinanceMeta: keep entrance motion minimal and invest custom motion in the operating loop itself.

## Inspira UI interaction references

Sources:

- https://inspira-ui.com/docs/en/components/cursors/fluid-cursor
- https://inspira-ui.com/docs/en/components/backgrounds/interactive-grid-pattern
- https://inspira-ui.com/docs/en/components/text-animations/text-reveal

Useful properties:

- Pointer input can visibly deform a field without moving interface content.
- A grid becomes meaningful when it holds routes, indices, and current state.
- Text entrances work best when grouped by editorial line, not applied to every word.

Transfer to FinanceMeta: implement these ideas in the existing React canvas and motion stack. Do not import the source library's Vue components or its visual styling.
